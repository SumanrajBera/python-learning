# Operators
- Operators are used to make expressions

## Arithmetic Operators
- `+` - For addition
- `-` - For subtraction
- `*` - For mutiplication
- `/` - For division
- `%` - For remainder
- `//` - For floor division
- `**` - For exponent
  
## Assignment operators
- `+=` 
- `-=`
- `*=`
- `/=` 
- `%=`
- `//=`
- `**=`

*Note*: We can only concatenate string with string. *Eg. "hello" + 3 - is wrong.*
*Note*: We can use `*` to multiply the times a string. *Eg. print("hello" * 3) - will print it 3 times*

## Comparision operators
- `==`: Equals to
- `!=`: Not equals to
- `>`: Greater than
- `>=`: Greater than equal to
- `<`: Lesser than
- `<=`: Lesser than equal to

## Logical operators
- `and` - AND operator
- `or` - OR operator
- `not` - NOT operator
