# Python Learning and Tutorial

This repository contains my Python learning journey, with examples, notes, and exercises covering Python fundamentals through more advanced concepts. 

Each directory focuses on a specific topic and contains the code and notes related to that topic.

## Repository Structure

| Directory                                              | What you'll find                                                                                                            |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [`basics`](./basics)                                   | Fundamental Python concepts such as variables, data types, input/output, type conversion, and basic syntax.                 |
| [`operators`](./operators)                             | Python operators including arithmetic, comparison, logical, assignment, membership, and identity operators.                 |
| [`conditionals`](./conditionals)                       | Conditional logic using `if`, `elif`, and `else`, along with examples of decision-making in Python programs.                |
| [`loops`](./loops)                                     | Iteration using `for` and `while` loops, including loop control statements and practical examples.                          |
| [`functions`](./functions)                             | Defining and using functions, parameters, return values, scope, and other function-related concepts.                        |
| [`ds`](./ds)                                           | Python data structures and examples of working with collections and their operations.                                       |
| [`file_exception_handling`](./file_exception_handling) | File handling and exception handling, including reading/writing files and handling runtime errors.                          |
| [`modulesPackages`](./modulesPackages)                 | Python modules and packages, imports, reusable code, and how Python organizes code across files.                            |
| [`oops`](./oops)                                       | Object-oriented programming concepts including classes, objects, inheritance, abstraction, encapsulation, and polymorphism. |
| [`advance`](./advance)                                 | More advanced Python concepts and examples built on top of the fundamentals covered in the earlier directories.             |

## How to Use This Repository

The directories are generally organized from fundamental Python concepts toward more advanced topics.

If you're starting with Python, a reasonable path is:

**Basics → Operators → Conditionals → Loops → Functions → Data Structures → File & Exception Handling → Modules & Packages → OOP → Advanced**

Each directory can be explored independently once you are familiar with the prerequisite concepts.
